## ✨ Core Features

* **⚡ Interactive 50+ Command Terminal**: Integrated client-side shell OS with custom commands, shortcuts, dynamic chips, and easter eggs.
* **🌌 Dynamic Canvas Particle System**: Real-time canvas physics with interactive cursor attraction and warp-speed motion toggle.
* **🟢 Matrix Digital Rain Simulation**: One-click togglable Matrix green rain canvas overlay.
* **🎵 Web Audio Synthesizer**: Native JavaScript Web Audio API sound wave generator for seamless UI click/hover chimes.
* **🕒 Live Real-time Clock**: Navigation bar live clock tracking system local time.
* **💬 Pre-filled WhatsApp Integration**: Direct lead capture modal routing users to WhatsApp with custom pre-formatted text.
* **🎯 Modern UI/UX Architecture**: Glassmorphic dark cyberpunk aesthetic with high-performance responsive tilt physics.
